# HTML 动效制作指引

配方字段、默认时长、各配方用在哪，见 `skills/jianying-ai-editor/references/packaging-rules.md`。
本页讲怎么把一个关系做成能读懂的动效。

1. **先写观众应看懂的关系。** 过程先后用 `steps`，同口径的两组选项用 `compare`，一个数值用 `number`，已经完成的项目用 `checklist`。例如「教学时间从 30 分钟降到 12 分钟」，如果要读出变化前后，两端都写明单位，用对比卡。如果只强调最终耗时，就让数字和「分钟」占同一视觉中心。把选好的文案和数据直接填入内置配方，制作和渲染都用 MCP。

   `list`、`steps`、`checklist`、`compare` 都会复述主讲刚说过的话。放在小节里只能进 `layout.with.graphic` 随讲随出；**全屏使用只允许出现在总结段**，在第一拍标 `role:"summary"`，否则编译直接报错。`number`、`quote`、`headline` 是强调卡，可以全屏短停。
2. **从稳定画面倒推入场。** 先放结论或主数字，再放标签、单位和必要条件。按最终画幅检查最长标题、最大数值和最后一项。在分屏里，用 `compile_episode` 的 `layout.with.graphic` 按栏位尺寸生成。例如 480 × 800 的上下均分画面，单独试做动效就用 480 × 400。按目标手机尺寸看，读不清时先缩短标签或拆成两拍。
3. **为每次运动找一句原声。** 用带时间码的转写找步骤的动词或数字的重音。`list`、`steps`、`checklist` 支持 `items[].at`，单位是从本镜开始算的秒。例如原片从 10.00 秒取用，第二步说在 12.40 秒，本镜又从成片 5.00 秒开始，填 `at=2.40`，在成片 7.40 秒复查。`at` 必须按出现顺序递增，省略的项按前一项加固定间隔顺延。一个时点安排一个最该看的变化，前项停稳后保留上下文。最后一项入场后给观众留出复述结论的时间。
4. **先试一镜。** 用 `create_motion_clip(render=false)` 生成工程，在 `look_openfilm` 分别看首帧、下一项出现前、变化中和结束后的稳定画面。有现成自定义 HTML 时可交给 `create_video_animation`。它的 `window.film.frame(t)` 要能用镜头内秒数直接还原画面，字体和图片随工程从本地加载。列表编号从首帧就设好字宽、对齐和底色，整行只改变透明度与少量位移。若编号在淡入中途突然横移，逐帧检查那一刻是否切换了字体、对齐方式或边距。先跳到后段，再跳回同一秒，对照两次截图里的文字、位置和数值。
5. **回到交付尺寸和成片验收。** 用 `create_motion_clip(render=true)` 或 `render_openfilm` 得到 MP4，在 `review_export` 指定短区间检查实际帧，入轨后再看分屏合成。通过时应能边听边指出当前项、读全最终数值及单位，分栏边界没有裁字，尾帧有读完最后一项的停留。出现太早就校正相对入点，尾项来不及读就前移或延长镜头，分屏裁字就改标签或布局。

记录「成片区间（单镜素材注明镜头内秒）｜预期｜实见｜结论」，时间采用实际返回的 `frames[].time_ms`。
只有工程时先记工程预览结果，导出 MP4 后补成片实见。清单里的 `at` 只说明排了时点，没有看到画面时写「待目检」。
复刻时保留配方、风格、画幅和帧率，换一段原声就重新标入点。
