# 分镜制作指引

beat 类型、分屏参数、配方字段和固定的包装取值，见 `skills/jianying-ai-editor/references/packaging-rules.md`。
本页讲怎么决定每一拍剪什么、为什么在这里切。

## 先交付可以直接执行的脚本

Agent 收到需求后，先把本期原声和画面动作按时间摆在一起，再开始渲染。南安普顿大学的制作流程用双栏脚本对齐“观众听到什么”和“观众看到什么”。在剪映工作流中，加上成片时码、选材和字幕入点，脚本就能直接用于制作。[南安普顿大学视频制作流程](https://www.southampton.ac.uk/digital-learning/media/services/video-production.page)

| 成片 | 声音 | 画面与执行 |
| --- | --- | --- |
| 0–6 秒 | 主讲说明客户为什么会担心发错货 | 保留实拍。普通陈述用一句字幕，让观众先认清讲者。 |
| 6–12 秒 | “先对货号，再数件数，最后核地址” | 上方 HTML 步骤卡逐项出现，下方保留主讲。可让卡片承载列举，口播字幕避免重复占满画面。 |
| 12–18 秒 | 主讲讲到封箱 | 用 `stock.query="手持胶带机沿纸箱接缝封口"`，取够六秒的真实候选。需要看清操作时全屏，需要看讲者反应时上下分屏。 |
| 18–24 秒 | 主讲讲本期的实际结果 | 回到实拍。自然递进的两句可以整项淡入，前项保留到本组结束。 |

用 `plan_video_script` 保存脚本表和可执行参数。素材库无合适画面时，Agent 可换词搜索；采用 `keep_camera` 时在回执说明原因。无须为凑够三类素材而插入无关镜头。执行工具为 `execute_video_script`。脚本表先提供给用户，用户明确要求先审稿时再等待确认。

卖家口播以 `seller_reference` 为起点。遇到客户疑问、操作过程或成果，先查 `search_broll_shots` 检索剪映库存的对应动作（可先设 min_duration_ms=6000）。要看清动作细节时全屏，要同时看到解释者时用上下分屏。将选中的 `shot_id`、成片入点 `at`、时长 `duration` 填入 `broll`。一个完整动作通常留 5–8 秒。卖家风格默认以 4 秒检查可见分镜，包括回到讲者的间隙。字幕和卡片内的逐项变化可跟随原话。数量和步骤可用随口播入场的图卡，故事结尾也可保留主讲人的结果句。

自动入轨时搜索 `availability="timeline_ready"`。能在本地解码的镜头也可用 OpenFilm 预览。仅能在剪映播放的缓存，先核对画面和时长，以 `editor_verified_ms` 入库。用 `bind_jianying_stock_selection(selection, shot_ids)` 绑定专用官方素材采集时间线中指向同一缓存的原生记录。绑定成功后状态为 `native_draft`，用剪映预览与导出。未取得可读取的记录时保留 `editor_only`。

1. **先写一句观众看完应能复述的话。** 回到素材，找出支撑它的一句原话、一个动作或一个可见结果。记下素材名、原片入出点和说话人。把「只在……时」「最多」「还没有」连同数字、单位一起保留。这些词决定剪出的结论是否真实。
2. **把每拍写成可剪的决定。** 在工作笔记里为每拍留一行「原片区间和原话｜成片中的作用｜观众该看哪里｜为什么在这里切」。传给工具时只填它支持的字段。教程先让人认出操作对象，再看到操作和反馈。访谈先交代谁在说，再用原声或画面支撑判断。找不到对应画面时，保留讲述者，或换用有证据的镜头。
3. **先试剪故事。** 讲者说「打开预览才能看到改动」时，从人脸切到按钮，在同一画面留到预览真的改变。小节切换用口播、镜头或转场交代。`chapter` 作为剪点标记，画面上省去额外的小节标签。
4. **再定构图和节奏。** 逐拍指明主体位置。把字幕放在能看清嘴型、手势和界面标签的区域。先让观众看见结果再切走。回放时若必须倒带才能认出变化，就延长结果画面或删掉与它抢视线的元素。字幕动效用 `caption_mode` 选呈现方式（`single`/`stack`/`blocks`/`words`，各自带入场动画），按拍用 `caption: {mode, zone}` 覆盖；`list_video_editing_modules(category="caption")` 只有字幕主题和高亮两个模块，不含动画。制作分屏动效时查 `list_motion_recipes`。用内置 `compile_episode` 填节拍和分屏，保留分镜输入作下一集的起点。字幕默认去掉逗号句号等停顿标点，回听核对时按清理后的文本走。
5. **收束。** 客户故事可让讲者说完结果。需要一起回看多个要点时，用卡片承载主讲原声，例如 `{"kind":"graphic","recipe":"compare","role":"summary","voice":{"source":…,"start":…,"end":…,"text":…},"data":{…}}`。工具裁出这段人声放旁白轨，字幕跟着这段话走，要点用 `items[].at` 对齐。
6. **从成片验收。** 挑「判断转证据」「动作转结果」等最影响理解的两个切点，各看前后两边。先静音看视线能否自然找到下一拍的主体，再带声听完整句和换气。通过时应能复述一句主旨、指出支撑它的那一帧，否定与条件仍跟着原话，切点两侧没有突断的动作或音节。单镜作品看开头建立主体和结尾交代结果。

审片记录写成「成片区间｜预期｜实见｜结论」。例如「5.20–5.80 秒｜点击后出现确认标记｜画面已切回人脸，标记未出现｜延长录屏，再查同一处」。
结构校验和清单只能说明字段齐全，没看到画面时写「待目检」。复刻下一集时沿用镜头作用、版式和验收问题，按新素材重新找原话、操作和时间点。
