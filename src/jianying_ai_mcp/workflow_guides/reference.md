# 参考草稿或参考成片

`analyze_reference_draft` 提供轨道、片段和效果结构。参考成片可用 `analyze_video_source` 观察切点、段落、字幕位置和音画关系。Agent 可按任务挑选要参考的节奏、构图或包装。

`build_from_reference` 可生成换料后的新草稿。默认试运行，返回轨道与片段数，随后清理暂存副本。

## 三种卖家口播的剪法

下表来自《不用操心10》《大单8》《复盘11》的本机时间线。三份根草稿均为 1080 × 1920，同工程 ID、时长与轨道结构的备份均标为 30 fps。下文时间为成片秒数，源素材入点需要另查。主轨段数只计第一条视频轨；文字片段包括强调字与编号，音效单列，均按实际使用的片段计数。

| 草稿 | 时长 | 主轨段数与播放速度 | 文字轨 / 段 | 单个文字片段时长中位数 | 音效段 |
| --- | ---: | --- | ---: | ---: | ---: |
| 不用操心10 | 40.33 s | 7 段，1.20–1.22× | 3 / 24 | 1.55 s | 13 |
| 大单8 | 43.10 s | 13 段，1.15–1.16× | 4 / 37 | 1.17 s | 23 |
| 复盘11 | 49.77 s | 7 段，1.18–1.22× | 10 / 38 | 1.70 s | 28 |

### 客户故事 · 不用操心10

- 0–3.70 秒，同一镜头先出“我们都懂工具”，1.60 秒补“懂构图”，2.53 秒补“懂色彩搭配”。三条同刻退场，三次入点各有一个短音。首段缩放关键帧从 1.35 到 1.56，形成轻推近。
- 7.87–10.70 秒把“把产品交给你之后”和“能不能放心？”分两次说完。13.87–19.93 秒讲到半夜的消息，模糊底层上叠聊天视频和人物层。聊天素材抽帧能看到消息气泡；这一段主轨音量字段为零，换素材时要单独确定对白来自哪一层。
- 20.17 秒起回到讲述和双方回应。37.73 秒“不用操心”进入强调轨，和结论一起收束。新题材可保留“担忧 → 真实交互 → 客户反馈”这个顺序，把聊天或交付截图放在说到它的那一句。

### 前后对照 · 大单8

- 0.13–2.53 秒把“卖家为什么”和“不敢把大单交给你”分成两次落字。3.90 秒切入桌边交谈素材。16.43–19.53 秒讲到最核心的产品，叠现场拍摄素材和人物层，背景加模糊。两处现场内容已用源素材抽帧核对。
- 25.87 秒先出“你半年前的图”，27.20 秒第二句和独立的黄色 `VS` 同时出现，28.50 秒一起收走。打字声从 25.87 秒起，短促的“biu”在 27.20 秒落下。原稿这段由文字做对照；新一期有可比的前后样张时，也可以把样张配在两句原话旁边。
- 35 秒起回到“成长 → 信任 → 交付”的因果关系，35.00–37.73 秒另叠拍摄现场。剪这类题材时先找出客户改变决定的依据，再选能说明它的镜头。

### 方法清单 · 复盘11

- 11.97–20.10 秒用模糊和“文本框便签”承载三组自问。三组标题在 11.97、14.20、16.87 秒出现，解释各晚约一秒，六段文字全部留到 20.10 秒。标题配“叮”，解释配“叮铃，任务完成”。
- 20.33 秒转到具体发现“前期沟通不充分”。29.27 秒先出大号“3”，30.47–39.57 秒改为上方问题、下方人物。编号 1、2、3 分别在 30.47、33.90、36.67 秒进入，每个编号只留到本题结束。
- 39.57 秒回到人物讲返工率下降，42.57 秒换收尾镜头。新一期先标出每个问题的首字，再排对应的编号、提示音和结果句。需要同时阅读多项时可用逐项保留的清单，逐题讲解时则让上一题退出。

### 字幕、声音与构图

三稿在第一句观点转折处各用了一次圆形蒙版，均挂在主轨第二段。《不用操心10》在 6.27–7.80 秒说“他只知道一件事”，《大单8》在 5.43–6.50 秒说“你越专业”，《复盘11》在 5.87–7.47 秒说“我现在有个好习惯”。新稿可把这个短暂的构图变化留给从铺垫转入观点的那句话。

三个首镜头都引用了已启用的实时降噪，强度字段均为 0.85。对比度字段依次约 0.14、0.30、0.18，锐化约 0.21、0.26、0.21；色温方向随拍摄环境变化。批量处理时，可用同一机位的一帧定人物肤色与白平衡，再把该组参数用到相同光线的镜头上。

三稿的常用正文字体为猫啃网烟波宋-B，常用字号为剪映富文本字段 12。正文色取自各字符区间的填充，白色配淡黄 `#FFF589`，常规字幕带黑色阴影，居中的主字幕常落在 `transform_y ≈ -0.435`。独立的数字、对照符和便签解释另设大小与位置。先让观众看清主体，再留出与下一句共存的空间。

三稿各有一条接近全长的配乐，音量字段依次约为 0.29、0.22、0.15。以音效起点距任一文字片段入点前后 0.10 秒为口径，三稿分别命中 10/13、18/23、24/28 次。制作新稿时先标问题、提示与答案各自的落字帧，再放提示音。以上数值是草稿记录，响度、字体替换和最终混音以实际导出为准。

## 接入批量剪辑

使用 `style_preset="seller_reference"` 将白字、淡黄强调、阴影和硬切写入新草稿。需要复现“懂工具 → 懂构图 → 懂色彩搭配”的次序时，给口播拍设置 `"caption":{"mode":"stack","cues":[{"at":0,"text":"我们都懂工具"},{"at":1.60,"text":"懂构图"},{"at":2.53,"text":"懂色彩搭配"}]}`。有短暂构图转折时，可在对应拍设置 `"circle_mask":{"at":0,"duration":1.3,"center":[0.5,0.35],"diameter":0.72}` 并按人物实际位置调整。补充画面从剪映库存用 `search_broll_shots` 搜索，通用情景镜头用于说明过程，具体客户反馈使用本期提供的凭证，按台词入点把 `shot_id` 填进 `broll`，同一批可混用全屏覆盖和人物分屏。

1. 以三份草稿建立设计蓝图。用 `analyze_reference_draft` 查看主讲转举例的时机、讲者与副画面的比例、字体、叠字及动画入点。制作本期时从新的口播与剪映库存视频开始。
2. 每个完整意思尽量用一个构图。常规镜头可先留 5–8 秒，图卡逐项入场时可停留更久。全屏、分屏和回到讲者都计入停留时长。卖家风格默认 4 秒下限，字幕按原话落字可跨越同一画面。
3. 先验收一条再批量复用。预览从讲者转入库存镜头和返回讲者的剪点，确认观众有时间看清动作。分屏检查脸、字幕和操作区，再听一次主讲原声与提示音。

`examples/episodes/seller-project-review.json` 给出 32 秒的分镜骨架，需替换为本期主讲与检索得到的两个剪映库存镜头 ID。

### 其他 Agent 可直接复用的后台调用示例

先用 `search_broll_shots(query="手持胶带机沿纸箱中缝封口",min_duration_ms=6000,availability="timeline_ready")` 查找可连续使用六秒的镜头，再用 `get_broll_shot` 核对画面描述、源片区间与出处。下列参数交给 `place_broll_shots`。把示意路径、台词和镜头 ID 替换为本期内容，台词要与实际原声一致。

```json
{
  "spec": {
    "name": "本期交付复盘",
    "style_preset": "seller_reference",
    "beats": [
      {"kind":"talk","source":"本期主讲绝对路径","start":0,"end":6,"text":"出库以前，我们先核对每一箱的货号。"},
      {"kind":"talk","source":"本期主讲绝对路径","start":6,"end":12,"text":"核对完件数，才开始封箱。","highlights":["封箱"]},
      {"kind":"talk","source":"本期主讲绝对路径","start":12,"end":18,"text":"最后扫一次运单，再交给快递。"}
    ]
  },
  "placements": [
    {"shot_id":"本期检索所得ID","at":6,"duration":6,"layout":{"kind":"stacked","main":"bottom","split":0.48}}
  ],
  "dry_run": false
}
```

这个例子把封箱实拍放在第 6–12 秒的上栏，讲者留在下栏。要看清整个操作画面时可改为 `{"kind":"full"}`。以回执中 `readback` 的轨道、实际时码与静音状态验收；`editor_only` 表示编辑器可预览，尚缺后台入轨所需的可读视频或原生引用。
